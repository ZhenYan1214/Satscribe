  2. NFT 仍無法購買: Season 20254 仍顯示 active: false

步驟 1: 清除所有緩存

步驟 2: 激活 NFT 季度

步驟 3: 重新設置分潤

步驟 4: 完整測試

📋 手動修復指令

如果按鈕不工作，請在前端控制台 (F12) 執行以下代碼:

🔧 修復代碼包 (全部複製執行)

// Satscribe 緊急修復腳本 import { uintCV, standardPrincipalCV, listCV, tupleCV, boolCV, stringAsciiCV } from '@stacks/transactions' console.log('🚨 開始 Satscribe 緊急修復...') // 1. 清除所有緩存 console.log('🗑️ 清除前端緩存...') const contractsStore = useContractsStore() contractsStore.clearCache('all') localStorage.removeItem('nft_metadata_ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ_20254') // 2. 激活 NFT 季度 20254 console.log('⚡ 激活季度 20254...') try { const activateResult = await contractsStore.walletStore.callContract( 'ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ', 'subscription-nft-v6', 'toggle-season-status', [uintCV(20254)] ) console.log('✅ 激活結果:', activateResult) } catch (error) { console.error('❌ 激活失敗:', error) } // 等待 3 秒讓交易處理 await new Promise(resolve => setTimeout(resolve, 3000)) // 3. 重新設置分潤 (60% + 25% + 15% = 100%) console.log('💰 設置分潤配置...') const teamMembers = [ { walletAddress: 'ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ', percentage: 60, role: 'creator' }, { walletAddress: 'ST36GD5YAN72KFMTRJEZZYWRSNPRGMBYV88MJRX0M', percentage: 25, role: 'artist' }, { walletAddress: 'ST2BC61X7GBDQ547WX2W72WG66288NQ5VZ66AMFJH', percentage: 15, role: 'manager' } ] try { const revenueResult = await contractsStore.setupRevenueSplit(teamMembers) console.log('✅ 分潤設置結果:', revenueResult) } catch (error) { console.error('❌ 分潤設置失敗:', error) } // 4. 等待並驗證結果 console.log('⏰ 等待區塊鏈確認...') await new Promise(resolve => setTimeout(resolve, 5000)) // 5. 強制重新載入數據 console.log('🔄 強制重新載入數據...') const seasonInfo = await contractsStore.getSeasonInfo('ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ', 20254, true) const revenueInfo = await contractsStore.getRevenueSplit('ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ', true) console.log('📊 季度狀態:', seasonInfo) console.log('💰 分潤狀態:', revenueInfo) if (seasonInfo && seasonInfo.active) { console.log('🎉 NFT 季度已激活！') } else { console.log('❌ NFT 季度仍未激活，需要重試') } if (revenueInfo) { console.log('🎉 分潤配置已設置！') } else { console.log('❌ 分潤配置仍未生效，需要重試') } console.log('🚨 緊急修復完成！請重新載入頁面測試。')

🧪 驗證步驟

  1. 執行上述修復代碼
  2. 等待所有交易確認 (約 2-3 分鐘)
  3. 重新載入前端頁面 (F5)
  4. 檢查分潤設置頁面是否顯示正確配置
  5. 嘗試 NFT 購買，應該成功
  6. 驗證分潤是否正確分配

⚠️ 如果仍然有問題

可能的原因和解決方案:

  • 交易未確認: 等待更長時間 (5-10 分鐘)
  • 網路問題: 檢查錢包網路設置 (測試網)
  • 錢包權限: 確認使用正確的創作者錢包
  • Gas 不足: 確認錢包有足夠的 STX
  • 合約問題: 可能需要重新部署合約

調試命令:

// 檢查錢包狀態 console.log('當前錢包:', useWalletStore().userAddress) // 檢查合約狀態 console.log('合約地址:', useContractsStore().CONTRACT_ADDRESS) // 手動檢查季度 const result = await useContractsStore().walletStore.readContract( 'ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ', 'subscription-nft-v6', 'get-season-info', [standardPrincipalCV('ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ'), uintCV(20254)] ) console.log('季度狀態:', result)

📞 最終解決方案

如果以上所有方法都無效，可能需要:

  1. 重新部署合約: 使用新的合約版本
  2. 創建新季度: 使用 20255 或其他季度 ID
  3. 檢查網路狀態: 確認測試網正常運行
  4. 清除瀏覽器數據: 完全重置前端狀態
