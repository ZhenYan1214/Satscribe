🎨 創作者 NFT 創建指南

您需要先以創作者身份創建 NFT 季度，然後用戶才能購買。

⚠️ 重要提醒

目前購買失敗的原因：

  • 創作者還沒有創建季度 20254 的 NFT
  • 用戶無法購買不存在的 NFT
  • 需要先創建，再購買

📋 解決步驟

步驟 1: 切換到創作者錢包

確保您使用的是創建內容的創作者錢包地址

創作者地址應該是：
以 ST 開頭的 Stacks 地址
例如：ST2FGWKW4M6KBY2P19WZRDH9TCDMGMTDGA2D301HQ

步驟 2: 進入創作者儀表板

在 Satscribe 應用中：

  1. 點擊右上角的個人頭像
  2. 選擇「創作者儀表板」
  3. 或直接訪問 /creator/dashboard

步驟 3: 創建 NFT 季度

  1. 進入「訂閱管理」頁面 (/creator/subscriptions)
  2. 點擊「創建新季度 NFT」按鈕
  3. 填寫以下信息：
    • 價格： 10 STX (不要輸入更大的數字)
    • 圖片： 上傳您的 NFT 圖片
    • 描述： NFT 的描述文字
    • 分潤機制： 根據需要啟用
  4. 點擊「創建季度」
  5. 確認交易

步驟 4: 等待確認

等待區塊鏈確認交易（約2-3分鐘）

確認後，季度 20254 將會創建成功

步驟 5: 切換到購買者錢包

現在可以切換到不同的錢包地址：

  1. 斷開當前錢包連接
  2. 連接不同的錢包地址
  3. 確保新錢包有足夠的 STX (至少 10 STX)

步驟 6: 購買 NFT

現在就可以正常購買了：

  1. 回到探索頁面
  2. 找到 zhenyan 的文章
  3. 點擊「購買訂閱權」
  4. 確認交易

✅ 成功指標

以下情況表示創建成功：

  • 創作者儀表板顯示新的 NFT 季度
  • 用戶可以在探索頁面看到購買按鈕
  • 點擊購買不再出現「不存在」錯誤

🔧 故障排除

問題：創建 NFT 時出現錯誤

  • ArithmeticUnderflow： 使用手動季度創建
  • already-exists： 季度已存在，直接進行購買測試
  • not-authorized： 確保使用正確的創作者錢包

問題：用戶仍然無法購買

  • 檢查季度是否真的創建成功
  • 確保購買者錢包有足夠餘額
  • 確保購買者錢包不是創作者錢包

問題：價格顯示異常

  • 創建時只輸入 10，不要輸入 10000000
  • 系統會自動轉換為 microSTX

📞 快速測試步驟

如果您想快速測試整個流程：

  1. 創作者錢包： 創建季度 20254
  2. 購買者錢包： 購買創建的 NFT
  3. 驗證： 檢查購買者的收藏
這樣就可以展示完整的 NFT 創建和購買流程！
